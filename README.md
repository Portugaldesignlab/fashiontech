# Portugal Design Lab — Cinematic Hero

A cinematic, award-site-grade hero section for **Portugal Design Lab**, an
innovation and design studio working across branding, product design,
AI-powered creativity, future concepts, R&D and strategic innovation.

**Designing Tomorrow Before It Exists.**

## What's inside

- **Dark luxury interface** — black / charcoal / silver / gold palette, film
  grain, vignette, glassmorphism cards
- **Generative canvas scene** — a luminous core orbited by node constellations,
  animated light trails connecting ideas, depth-of-field particles
- **Orbiting design artifacts** — the studio's fashion-tech pieces float as
  glass cards around the core, each tagged with a discipline
- **Motion system** — cursor-reactive lighting, depth-based mouse parallax,
  idle float, magnetic buttons, slow cinematic zoom, scroll-linked
  blur/recede, staggered blur-reveal choreography
- **Responsive + accessible** — mobile layout trims the orbit field,
  `prefers-reduced-motion` renders a calm static frame, semantic markup,
  alt text on every artifact

## Stack

Zero dependencies, zero build step: a single `index.html`, `styles.css`,
`script.js`. Fonts via Google Fonts (Space Grotesk · Instrument Serif · Inter).

## Run

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

## Images

Add the five campaign photos to `assets/images/` — see
[`assets/images/README.md`](assets/images/README.md) for the naming map.
Until they exist, each card shows a palette-matched gradient fallback.
